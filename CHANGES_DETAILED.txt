CHANGE 2: EXPORT FORMAT CHANGED FROM JSON TO TEXT DISPLAY
================================================================================

WHAT CHANGED:
Instead of exporting to essay_feedback.json, feedback is now:
1. Displayed directly in the app using formatted markdown
2. Can be downloaded as essay_feedback.txt (plain text)

OLD BEHAVIOR:
────────────────────────────────────────────────────────────────────────────
# User pastes essay
# User clicks "Get Feedback"
# Results appear in tabs
# User sees "Export Results" section with:
#   - Download button for JSON
#   - "JSON export ready for download" message
# User must download file and open separately to view

NEW BEHAVIOR:
────────────────────────────────────────────────────────────────────────────
# User pastes essay
# User clicks "Get Feedback"
# Results appear in tabs
# Feedback automatically displayed below tabs in formatted text
# Shows:
#   - Overall Assessment
#   - Priority Areas to Address
#   - Actionable Recommendations
#   - Rubric Scores Summary
# User can optionally download as .txt file

CODE CHANGES:
────────────────────────────────────────────────────────────────────────────

BEFORE (lines 487-509):
    # Export option
    st.markdown("---")
    st.markdown("#### 💾 Export Results")
    
    export_data = {
        "essay": essay_input[:500] + "...",
        "structure": results["structure"],
        "rubric_scores": {...},
        "feedback": results["feedback"],
    }

    col1, col2 = st.columns(2)
    with col1:
        st.download_button(
            label="📥 Download JSON",
            data=json.dumps(export_data, indent=2),
            file_name="essay_feedback.json",
            mime="application/json",
        )

AFTER (lines 487-530):
    # Display feedback results directly
    st.markdown("---")
    
    # Create formatted feedback display
    feedback_text = "# 📋 DETAILED FEEDBACK REPORT\n\n"
    
    # Add overall assessment
    if results["feedback"].get("overall_feedback"):
        feedback_text += "## Overall Assessment\n\n"
        feedback_text += results["feedback"]["overall_feedback"] + "\n\n"
    
    # Add priority areas
    if results["feedback"].get("priority_areas"):
        feedback_text += "## Priority Areas to Address\n\n"
        for area in results["feedback"]["priority_areas"]:
            priority = area.get("priority", "medium").upper()
            area_name = area.get("area", "")
            description = area.get("description", "")
            feedback_text += f"**[{priority}] {area_name}**\n\n{description}\n\n"
    
    # Add actionable advice
    if results["feedback"].get("actionable_advice"):
        feedback_text += "## Actionable Recommendations\n\n"
        for i, advice in enumerate(results["feedback"]["actionable_advice"], 1):
            feedback_text += f"{i}. {advice}\n\n"
    
    # Add rubric scores
    feedback_text += "## Rubric Scores Summary\n\n"
    for category, data in results["rubric"].items():
        if isinstance(data, dict) and "score" in data:
            score = data["score"]
            feedback_text += f"- **{category.replace('_', ' ').title()}**: {score}/5\n"
    
    # Display and allow download
    st.markdown(feedback_text)
    
    st.markdown("---")
    col1, col2 = st.columns(2)
    with col1:
        st.download_button(
            label="📥 Download Feedback (Text)",
            data=feedback_text,
            file_name="essay_feedback.txt",
            mime="text/plain",
        )
